# Noel Mills-Odoi — Portfolio Website

**Live at:** https://nmillso1.github.io

A whimsical pixel/retro portfolio site with Studio Ghibli warmth and Japanese idol game energy.

## Pages
- `index.html` — Home (hero, stats, features)
- `about.html` — About Me (story, flags, travel map, timeline)
- `projects.html` — Projects (animated canvas previews)
- `skills.html` — Skills (animated bars, tech cloud, certs)
- `contact.html` — Contact (links, fun facts)

## Features
- Dark/light mode toggle
- Walking pixel avatar with speech bubbles
- Animated project previews (canvas-based)
- Ambient lofi audio player (vinyl record)
- Floating emoji elements
- Pixel cursor trail
- Scroll reveal animations
- Responsive design

## Tech Stack
Vanilla HTML, CSS, JavaScript — no frameworks, no npm required.
Hosted on GitHub Pages.

## Deployment
1. Upload all files to your `nmillso1.github.io` repository
2. Enable GitHub Pages in repo Settings → Pages → Source: main branch
3. Site will be live at https://nmillso1.github.io
